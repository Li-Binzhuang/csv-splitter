# 设计伙伴访谈提纲（30 分钟）

> 目的：确认问题、数据边界、验收口径，不收集凭据或未脱敏 PII。
> 访谈记录只保留结论与匿名编号，不记录原始行内容。

## 1. 当前工作流

1. 你们每月处理多少份 CSV/TSV？最大多大？
2. 现在用什么打开、过滤、核对？哪一步最慢？
3. 失败/超时时你们怎么发现？谁负责重跑？

## 2. 数据与合规

4. 样本能否脱敏到列级？删除日期是哪天？
5. 数据是否允许留在本机临时目录？是否需要加密盘？
6. 谁有权运行 csvx？是否需要共享机器？

## 3. 验收

7. 一个具体问题是什么？期望输出是什么？
8. 现有工具耗时/RSS 基线是多少？
9. 正确性如何对照（逐行、聚合、抽样）？
10. 不达标时接受什么替代方案？

## 4. 记录格式

访谈后只写：

```text
partner: P-001
date: YYYY-MM-DD
sample: de-identified, N GB, columns listed
question: ...
baseline: ...
acceptance: ...
decision: go / no-go / fix-first
```

不写原始行、客户名、账号、token、精确地址。结论进入 `pilot-report.md` 与
`kickoff.json`；定价和合同另行人工确认。
