## 3. 交付物
- 用 csvx pipeline 复现的工作流与清单；
- 一份 `docs/PILOT.md` 格式的样本报告（扫描/导出/质量耗时、RSS）；
- 2 页总结：现状 vs csvx、可节省工时、风险与下一步；
- 2 次远程培训（各 60 分钟）。

## 4. 成功标准（示例，需双方填）
- 客户能独立跑通一遍；
- 目标工作流墙钟时间下降 ≥ {X%}，或人工步骤减少 ≥ {N}；
- 输出与人工结果逐行/逐字节一致（抽样 {N} 行）。

- 全程本地运行；不上传、不遥测；

- 客户可要求离线/断网环境。

- 未在报告中实测的性能承诺。
